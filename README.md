# LG DevMode Keeper

LG webOS 2.x için deneysel geliştirici oturumu yenileme yardımcı uygulaması.

**Uyarı:** webOS 2.x arka plan zamanlayıcısı ve LG oturum yenileme hizmeti üzerinde gerçek cihaz doğrulaması yapılmamıştır. Uygulamanın IPK olarak paketlenmesi otomatik yenilemenin çalıştığını garanti etmez.

Sürüm: 1.0.3, Build #4 BETA. XIPTV Play depolarından bağımsızdır.

GitHub Actions > Build webOS IPK > Artifacts bölümündeki IPK indirilebilir. Telefonunuza APK değil, TV'ye IPK yükleyin.
